## Spec

**F1 — P2, `drain()` does not establish worker completion.** [Execution::drain](/D:/Code/Arxcovo/crates/arxd/src/development/mod.rs:322) now returns success solely from `busy == false`. [dispatch](/D:/Code/Arxcovo/crates/arxd/src/development/mod.rs:366) schedules a blocking worker without registering pending work; `busy` is acquired inside `work`, and its guard is dropped when `work` returns, before dispatch calls `finish_typed`. Thus a queued worker, a worker refusing before acquiring busy, or a worker waiting to commit its terminal audit can coexist with `drain() == true`. [Foreground shutdown](/D:/Code/Arxcovo/crates/arxd/src/main.rs:130) interprets that boolean as successful drain, and foreground then calls `process::exit(0)` at line 62. A shutdown during the audit interval can terminate the process with a started row and clean exit despite unobserved completion. SQLite may recover it as interrupted on restart; that does not make the earlier completion observed.

The underlying busy-only drain predates this feature; the new boolean/exit handling leaves this existing weakness unresolved while adding a completion signal. The five-second budget need not change. Necessary closure is tracking queued/running workers through terminal audit completion and testing the relevant queue/audit interval and nonzero foreground exit. The passing drain test only toggles busy manually, so it cannot disprove this path. This is a static reachable-path finding, not a runtime reproduction, and does not establish an escaped child or a token-policy bypass.

Other owner requirements are implemented in source: execution is opt-in by presence of a normal block; omitted mode defaults to current_user; workspace/environment/limits remain required; dedicated account syntax is bounded/local, rejects built-in service aliases, and collects no password. Unknown fields and old/new conflicts reject. Inventory-only configurations stay so. Legacy mode/acknowledgement labels retain their meaning. No extra product approval flow was introduced.
