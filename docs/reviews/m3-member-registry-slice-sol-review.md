# Member registry slice: independent Sol review

Target Opus548aafa retained21e623a,129-line brief and ADR0005 amendment. Standards PASS, Spec/Security conditional on R1/R2 below before implementation. Durable node/key authority independent of expiring enrollment dedup, atomic registration/revocation, replay refusal and bounded snapshots are the appropriate next slice. No TLS/source build ran in this review.

R1: local applied-state authorization has eventual, potentially unbounded revocation staleness. An isolated node can retain a removed binding indefinitely. Replace "bounded staleness" and any implied global-current guarantee with the exact limit, and state that this helper alone cannot authorize production control/execution under isolation. Future transport/control policy must resolve freshness versus quorum bootstrap availability; a local registry is not linearizable revocation proof. The current T4 correctly tests refusal only after Remove is applied or snapshot-installed. Certificate signing retains mandatory fresh quorum checks and is not implemented here.

R2: Found adds a variable-length Vec to an otherwise fixed-size command codec. Settle a finite canonical command bound before encoding/allocation, and distinguish wire/encoding validity from semantic BadFounders. A well-framed17-pair Found should reach semantic rejection without making a committed log undecodable; malformed/oversized payloads must fail before append and never truncate, cast-wrap or panic. Specify the actual bounded representation/error propagation and tests for maximum semantic-invalid payload, over-bound input and successful semantic rejection through the real store/engine. Snapshot registry count16 remains a separate invariant. Log MAX_ROW4163 and callback failure paths stay held.

Found replay should validate its structural1..16/node ordering/key uniqueness even after founded; empty input must not vacuously count as replay. Document replay as current-pair idempotence rather than a cryptographic commitment to the original bootstrap list unless the state stores that list. Remove/replay rules keep next_node monotonic and LastMember fail-closed.

Version1 refusal is acceptable for the explicitly nonproduction cluster store, with valid-checksum old images tested on open/install/peek and no DB mutation; mixed-version operation remains unsupported. Existing tests need genuine Found steps and index updates, not weakened assertions. Sixteen registry slots is an initial codec/storage bound, not a new product voter policy. The later certificate/CA handoff remains gated on its own implementation/security review and actual crypto/API checks. M2 remains open, A7/A12 no-retry unchanged.

Next: Opus narrowly closes R1/R2, coordinator rechecks, then Sol implements the real-engine registry slice. No broader enrollment redesign or repeated planning framework is needed.
