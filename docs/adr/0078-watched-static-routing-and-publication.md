# 0078 Watched static routing and publication

Status: proposed. Extends [ADR 0069](0069-vm-store-v13-multihost-publish.md) and [ADR 0077](0077-native-static-lifecycle.md).

## Decision

The Windows x64 foreground checks the held root custody, current M4 qualification, selected Docker dossier and reviewed network witness before advertising or admitting checked static effects. Route retirement withdraws the capability and the Compose recipe. The live boot owner retains its stop authority.

The daemon installs enrolled private routes over the attributed Compose serial channel after origin HTTPS verification and before committing the start. An acknowledgement belongs to the same wire boot. The guest reserves enrolled project slots before first deployment and validates the service index, name and HTTP port as releases deploy. Active public routes can extend the private table within the same routing bounds. An overlapping hostname must have the identical binding.

Public activation requires explicit opt-in, the enrolled profile and the current running origin. A routed activation also requires the serial session for that boot. Cloudflare credentials are loaded only after publish policy and target admission checks. The origin and route watch fence effects and publication settlement. On stop, the boot owner retires the origin and stops the connector before releasing the guest. It attempts owned DNS reconciliation before completing the stop. Restart requires a fresh verified boot and explicit publish.

Observed retirement interrupts explicit publish and unpublish effects. Local ingress stops first. DNS rows whose removal is unconfirmed retain their exact ownership markers and record evidence for the independent reaper. Reconciliation can remove only those owned records and never starts ingress. The recovery boundary in [ADR 0065](0065-vm-store-v10-publish.md) still applies if a possible POST survived a daemon failure without a recorded ID or durable proof of non-submission. Such an intent blocks replacement until ownership or safe release can be established. Static VM media, Compose projects and volumes, and settled backups retain their existing custody protections.

## Verification

The deterministic paths use attributed fake serial sessions, a fake connector and fake DNS. Native VM boot, Docker, public-only networking, Windows custody, persistence and live Cloudflare publishing remain **unverified on real hardware** pending [owner acceptance](../static-vm-acceptance.md).
