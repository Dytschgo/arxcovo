# Security

Do not disclose credentials, private logs or vulnerabilities in public issues. Use GitHub private vulnerability reporting when enabled; until available, do not send sensitive details publicly.

This scaffold is not ready to manage hosts. Future operations require technical fences, bounded reads, validated arguments and safe paths including reparse-point rejection. Agents cannot delete static VMs or backups. Public publishing defaults off.

Privileged CI policy must execute trusted default-branch code only. Independent reviewer status must use a separately authenticated integration, never builder CI.
